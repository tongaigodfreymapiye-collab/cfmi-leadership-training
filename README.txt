CFMI Leadership Certificate in Christian Ministry — App V1.1

This is a standalone Progressive Web App (PWA) front end.
It does NOT modify Google Forms, Apps Script, Master Register, grading, progression, certificates, transcripts, or triggers.

To preview locally:
1. Open a terminal in this folder.
2. Run: python -m http.server 8080
3. Visit: http://localhost:8080

To publish, upload the folder to any static HTTPS web host. PWA installation requires HTTPS (except localhost).

IMPORTANT: The Study Manual URLs were transcribed from supplied screenshots. Verify each manual button before public deployment. The Google Form assessment URLs were supplied directly and are mapped to Modules 101–105.
